---

پیام رسان پنل پیامکی موج شهر است. از سال ۱۳۸۷ پیامک کسب‌وکارها را می‌فرستد:
رمز یک‌بارمصرف ورود، اطلاع‌رسانی سفارش، یادآوری نوبت.

## نمونه‌کدها کجا رفتند

مخزن‌های نمونه‌کدی که پیش‌تر زیر همین حساب بودند، به سازمان
[موج شهر](https://github.com/Mojeshahr) منتقل شده‌اند تا همه‌ی کدهای عمومی یک
جای مشخص داشته باشند. نام هیچ مخزنی عوض نشده، فقط مالکش:
`payam-resan/php-sms-webservice` حالا `Mojeshahr/php-sms-webservice` است.

ستاره، فورک، ایشو و تاریخچه‌ی کامیت‌ها همراه مخزن رفته‌اند. گیت‌هاب نشانی قدیمی
را خودکار به نشانی تازه می‌فرستد، پس لینک‌های ذخیره‌شده و حتی `git clone` با
نشانی قبلی همچنان کار می‌کنند. اگر کلون محلی دارید و می‌خواهید ریموتش را اصلاح
کنید:

```bash
git remote set-url origin https://github.com/Mojeshahr/php-sms-webservice.git
```

## نمونه‌کد هر زبان

برای هر زبان یک مخزن جدا، با یک فایل قابل اجرا به‌ازای هر متد سرویس؛ بدون
وابستگی، آماده‌ی کپی در پروژه‌ی خودتان.
